FAQ

Pertanyaan yang sering diajukan

Apakah pelanggan harus memasang aplikasi?

Tidak. Pelanggan cukup memindai QR Code di meja dengan kamera HP; menu terbuka di browser.

Apakah pesanan dari HP pelanggan langsung muncul di dapur?

Pada prototype ini data disimpan di browser (LocalStorage), jadi hanya muncul di browser yang sama (mode simulasi antar-tab). Untuk dipakai nyata di banyak perangkat, aplikasi perlu dihubungkan ke Firebase — struktur kode sudah disiapkan untuk itu.

Apakah pembayaran QRIS terintegrasi otomatis?

Belum. Metode pembayaran (tunai, transfer, QRIS, lainnya) saat ini dicatat manual oleh kasir. Integrasi payment gateway dapat ditambahkan pada tahap berikutnya.

Apakah harga, foto, dan nama restoran bisa diganti?

Ya. Semua data contoh (termasuk nama, logo, harga, dan foto) dapat diedit lewat dashboard admin.

Bagaimana cara memasang QR di meja?

Di dashboard buka Manajemen Meja atau QR Code, atur Base URL ke alamat website Anda, lalu unduh PNG atau cetak QR tiap meja.

Apakah login admin sudah aman?

Login pada prototype hanya simulasi demo di browser dan tidak aman untuk produksi. Versi produksi memakai Firebase Authentication dan aturan keamanan database berbasis role.
